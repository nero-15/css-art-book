# 描いた絵を、合格するまで確かめて直す

`css-art-draw` の工程5（検証）を、目視ではなく数字で回すための手順と道具です。下絵の画像があるとき、次の3つを機械に任せられます。

- 下絵を測る（工程1と3の入力になる数字を出す）
- 描画する（ヘッドレスのChromeでスクリーンショットを撮る）
- 突き合わせる（食い違いの割合と場所を出し、合格か不合格かを決める）

この skill の内容は、書籍『CSSで絵を描く』には無い、このプラグイン独自のものです。設計と実装の決まりは `css-art-draw` に従います。

## 必要なもの

- Python 3 と Pillow（`python3 -m pip install Pillow`）
- Chrome、Chromium、Edge のいずれか（見つからなければ、環境変数 `CHROME` に実行ファイルのパスを入れる）

どちらかが無いときは、勝手に入れずに、無いことを伝えます。その場合は `css-art-draw` の工程5を目視で行い、報告に「画素の突き合わせは未実施」と書きます。

スクリプトは、この skill のフォルダの `scripts/` にあります。以下の `scripts/` は、そのフォルダへのパスに読み替えてください。

## ループ

```
1 測る ─→ 2 設計する ─→ 3 描く ─→ 4 描画する ─→ 5 突き合わせる ─┬─ 合格 → 6 仕上げの確認 → 終わり
              ↑                                                   │
              └──────── 7 原因を座標表で特定して直す ←─ 不合格 ──┘
```

| 手順 | やること | 道具 |
|---|---|---|
| 1 測る | 下絵の色と、絵の範囲と、行ごとの色の区間を出す | `scripts/measure.py` |
| 2 設計する | 測った数字から部品表と座標表を作る | `css-art-draw` |
| 3 描く | 座標表を写してCSSにする。検証用のページも作る | `css-art-draw` |
| 4 描画する | 下絵以上の大きさで撮る | `scripts/render.py` |
| 5 突き合わせる | 食い違いの割合、多いマス、差分画像を得る | `scripts/diff.py` |
| 6 仕上げの確認 | 24px、100px、400px と画面密度2倍で撮り、目で見る | `scripts/render.py` |
| 7 直す | 食い違いの多いマスの部品を、座標表まで戻って直す | 下の「直し方」 |

### 終わる条件

次の3つがそろったら終わりです。

- `diff.py` の判定が「合格」（既定では全体の食い違いが0.5%以下、かつ、どのマスも3%以下）
- 差分画像を開いて見て、赤い画素が輪郭に沿った細い線だけになっている（面で赤い場所が無い）
- 24px、100px、400px の描画を見て、崩れが無い

### やめる条件

次のどれかに当たったら、数字を動かし続けずに止まります。

- **2周続けて食い違いが減らない。** 微調整では直らない。手順1に戻って測り直すか、部品の分け方を変える
- **8周しても合格しない。** そこまでの記録と、残っている食い違いの場所、原因の見立てを報告する
- **下絵に、グラデーションや写真のような面がある。** この道具は「面積の大きい数色」に寄せて比べるので、合わない。目視に切り替える

### 記録

1周ごとに、次の1行を残します。最後の報告にそのまま載せます。

| 周 | 食い違い | 最も多いマス | 直したこと |
|---|---|---|---|
| 1 | 4.31% | x 40-50, y 30-40: 16.0% | （最初の描画） |
| 2 | 0.07% | x 70-80, y 70-80: 0.5% | Iの縦棒の左辺を 44.5 から 46.5 に直した（測った値の写し間違い） |

## 1 測る

まず引数なしで実行し、色の一覧と、絵の範囲の候補を見ます。

```sh
python3 scripts/measure.py 下絵.png
```

```
大きさ: 508×508
色（面積の多い順）:
  A #ffffff 41.1%
  B #0a2296 28.7%
  C #000000 18.5%
絵の範囲の候補（左上の角の色を背景と見た場合）: --box 2,6,502,506
```

絵の範囲（`--box`）は、方眼の (0, 0) から (100, 100) に当たる正方形です。候補が正方形でないときや、絵が画像の端で切れているときは、手で直します。範囲が決まったら、行ごとに測ります。

```sh
python3 scripts/measure.py 下絵.png --box 2,6,502,506 --step 2
```

```
  y=50: C 0.0-7.2  B 7.2-14.4  A 14.4-21.4  B 21.4-30.0  A 30.0-37.2  ...
```

「y＝50 の行では、色Aが x＝14.4 から 21.4 まで」と読みます。これがそのまま座標表の材料になります。

- 縦の線の位置は、どの行でも同じ x に出る。その値を読む
- 斜めの線は、2つの行の x の差 ÷ y の差が傾きになる。両端の点を決めて、`css-art-draw` の計算式に入れる
- 円は、中心を通る行の両端から半径が出る
- 横の線や、上下の端を知りたいときは `--columns` を付けて列ごとに測る
- 値は縁のにじみで±0.3ほどぶれる。線の太さや隙間が「7.0、7.2、6.9」のようにそろっていたら、きりのいい1つの値（7）に決める

## 3 検証用のページ

`render.py` は、ページを開いて左上の正方形を切り出します。絵を左上の角に置き、URLの `?size=` を絵の大きさに反映するページを用意します。

```html
<!doctype html>
<meta charset="utf-8">
<link rel="stylesheet" href="art.css">
<style>html, body { margin: 0; background: #fff; }</style>
<div class="art" id="art"></div>
<script>
  const size = new URLSearchParams(location.search).get("size");
  if (size) document.getElementById("art").style.setProperty("--size", size + "px");
</script>
```

- 絵の大きさは `--size` の1か所で決まるように作っておく（`css-art-quality`）
- 背景の色は、下絵の背景と同じにする。違うと、絵の外側がすべて食い違いになる
- このページとスクリプトは検証のためのもの。成果物には混ぜない

## 4 描画する

```sh
python3 scripts/render.py verify.html out.png --size 500
python3 scripts/render.py verify.html out@2x.png --size 100 --density 2
```

判定に使う描画は、**下絵の絵の範囲と同じか、それより大きい**画素数で撮ります。小さく撮ったものを比べると、拡大のにじみが食い違いに入り、正しい絵でも不合格になります。

## 5 突き合わせる

```sh
python3 scripts/diff.py 下絵.png out.png --box 2,6,502,506 --out diff.png
```

```
食い違い: 1.02%（2390 / 233604 画素。位置合わせ dx=0, dy=0）
食い違いの多いマス（方眼の範囲、マスの面積に対する割合）:
  x 40-50, y 50-60: 16.0%
  x 40-50, y 60-70: 16.0%
差分画像: diff.png
判定: 不合格（上限は全体 0.5%、1マス 3.0%）
```

- 下絵の色の境目から1画素は数えません。縁のにじみは描画ごとに違い、比べても意味が無いためです
- 位置は±2画素の範囲で自動で合わせます。「位置合わせが探す範囲の端です」と出たら、`--box` がずれています
- 合格なら終了コード0、不合格なら1を返します
- **差分画像は必ず開いて見ます。** 数字が合格でも、細い部品が丸ごと抜けていることがあります

## 7 直し方

食い違いの多いマスから、どの部品かを特定します。差分画像の赤の出方で、原因の見当が付きます。

| 赤の出方 | 原因の見立て | 直し方 |
|---|---|---|
| 1つの辺に沿った、同じ太さの帯 | その辺の座標が、帯の太さの分ずれている | 測った値と座標表を見比べる。写し間違いか、測る行の選び方を確かめる |
| 辺に沿った、くさび形（片方が太い） | 傾きが違う | 斜めの線の両端を、離れた2行で測り直す |
| 円に沿った、三日月形 | 中心がずれている | 中心を通る行と列を測り直す |
| 円に沿った、同じ太さの輪 | 半径が違う | 中心を通る行の両端から半径を出し直す |
| 部品が丸ごと赤 | 部品が抜けている、色が違う、重なりの順が違う | `css-art-troubleshoot` の「何も表示されない」「重なりの順番がおかしい」 |
| 絵の外側がすべて赤 | ページの背景が下絵と違う、または `--box` が違う | 背景の色と `--box` を確かめる |
| 絵全体に、同じ向きの細い帯 | 絵の範囲がずれている | `--box` を測り直す |

決まりは1つです。**CSSの数字を直接いじらない。座標表を直し、そこからCSSを書き直す。** 赤が減るまで数字を1ずつ動かすのは、`css-art-draw` が禁じている「目分量で詰める」と同じです。

直すのは1周に1か所です。複数を同時に直すと、どれが効いたか分からなくなります。

## 下絵の画像が無いとき

言葉の説明から描く場合は、比べる相手がありません。手順1と5を飛ばし、次で代えます。

- 手順4の `render.py` で 24px、100px、400px と画面密度2倍を撮り、目で見る
- 方眼を重ねて、頂点が座標表どおりの位置にあるかを見る（方眼のCSSは `css-art-draw`）
- 一度合格と決めた描画を保存しておけば、後で直したときに、それを下絵として `diff.py` に渡せる。意図しない変化を見つけられる

## 報告に書くこと

- 記録の表（周、食い違い、最も多いマス、直したこと）
- 最後の判定と、使った `--box`、描画の大きさと画面密度
- 描画したブラウザと版。確かめていないブラウザは「未確認」と書く
- 差分画像と、24px・100px・400px の描画のパス
- 合格しなかった場合は、残っている食い違いの場所と、原因の見立て
