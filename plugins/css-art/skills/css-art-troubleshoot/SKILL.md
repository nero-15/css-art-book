# CSSで描いた絵の不具合を直す

症状から引く早見表です。上から順に当たってください。多くの問題は、最初の2つの表で片付きます。

用語:

- **箱**: 1つの要素、または疑似要素が占める長方形
- **部品**: 絵を構成する1つの形。1つの箱で描けるとは限らない
- **ハードストップ**: グラデーションで、ぼかさずに色を切り替えること

コード例の色は、次の変数を前提にしています。

```css
:root { --green: #0f3d2e; --cream: #f4ecd8; --red: #e4572e; }
```

## 使い方

1. 症状に合う節の表を上から順に確かめる
2. 直し方を1つ入れたら、描画して結果を見る。複数の修正を同時に入れない
3. どの表にも当てはまらなければ「それでも分からないとき」の手順で原因を狭める

## 何も表示されない

| 確かめること | 直し方 |
|---|---|
| 要素に幅と高さがあるか | 空の `div` は高さ0。`width` と `aspect-ratio`（または `height`）を指定する |
| 疑似要素に `content` があるか | `content: ""` が無いと `::before` と `::after` は生成されない |
| 疑似要素に大きさがあるか | `position: absolute; inset: 0;` で親と同じ大きさにする |
| 色が背景と同じではないか | 仮に `background: red` を当てて、箱の位置を確かめる |
| `clip-path` の座標が箱の外に出ていないか | いったん `clip-path` を消し、箱が見えるか確かめる |
| `mask` で全部消していないか | いったん `mask` を消す。残す部分が `#000`、消す部分が透明になっているか見る |

**切り分けのこつ**は、`clip-path` と `mask` を一時的に消して、箱そのものが見えるかを先に確かめることです。箱が見えれば切り抜きの問題、見えなければ箱の問題です。

## 位置や形がずれる

| 症状 | 原因 | 直し方 |
|---|---|---|
| 部品が画面の左上に飛ぶ | 親に `position: relative` が無い | 絵のルートに付ける |
| 円が楕円になる | 箱が正方形でない | `aspect-ratio: 1` を付ける |
| 輪の太さが想定と違う | `radial-gradient` の100%が角までの距離になっている | `closest-side` を付ける（下の補足） |
| 枠線の分だけ大きくなる | `box-sizing` が既定のまま | `box-sizing: border-box` を付ける |
| 部品が親からはみ出す | — | 親に `overflow: hidden`、または親の形で `clip-path` |
| 斜めの線が合わない | 目分量で座標を決めている | 傾きから計算する（下の補足） |
| `%` の基準が想定と違う | `%` は親の大きさが基準。枠線があると内側の寸法になる | 部品を `inset: 0` にそろえ、`clip-path` の `%` で形を決める |
| 回したら位置がずれた | 回転の中心は箱の中央 | `transform-origin` を指定する。または回さず `polygon()` で描く |

補足:

- **`closest-side`**: `radial-gradient` の100%は、既定では中心から最も遠い**角**までの距離です。正方形の箱なら、辺までの約1.41倍になります。`closest-side` を付けると100%が辺までの距離になり、「半径の何%」という直感どおりに書けます
- **傾きからの計算**: 傾き ＝ 縦の変化 ÷ 横の変化。線の上の点は y ＝ 起点のy ＋ 起点からの横の距離 × 傾き。座標表の作り方は `css-art-draw` を参照

## 拡縮すると崩れる

| 症状 | 原因 | 直し方 |
|---|---|---|
| 小さくすると部品がずれる | px で書いた値が残っている | `%`、`em`、変数からの計算に置き換える |
| 小さくすると線がつぶれる | 細部が1px未満になっている | 小さいサイズ用に、細部を省いた版を作る |
| 影だけ大きさが変わらない | `box-shadow` は `%` を使えない | `em` で書き、`font-size` を絵の大きさに連動させる |
| 枠線だけ太さが変わらない | 同上 | `calc(var(--size) * 0.05)` のように計算する |

`em` を使う場合は、絵のルートで `font-size: calc(var(--size) / 10)` のように決めておくと、`1em` が絵の10分の1になります。置き換えの一覧は `css-art-quality` にあります。

## 縁や継ぎ目が汚い

| 症状 | 原因 | 直し方 |
|---|---|---|
| 円の縁がギザギザ | グラデーションのハードストップ | 境界に1ピクセル分の幅を持たせる（下の補足） |
| 部品の間に細い線が見える | 斜めの辺が半分ずつ塗られ、背景が透ける | 1つの形にまとめる。無理なら1%重ねる |
| 切り抜きの縁に背景色がにじむ | 同上 | 奥の部品を大きめに作る |
| ぼかしたグラデーションの途中が黒ずむ | `transparent` が「透明な黒」として扱われるブラウザがある | 同じ色のアルファ0を使う（赤なら `rgb(228 87 46 / 0)`） |
| ズームすると隙間が出たり消えたりする | 小数ピクセルの丸め | 部品を重ねる。座標を整数の `%` に寄せる |

補足: 境界に1ピクセル分の幅を持たせる書き方は次のとおりです。詳しい理由と選択肢は `css-art-quality` にあります。

```css
.rings {
  --aa: 1px;
  background: radial-gradient(closest-side,
    var(--green) calc(60% - var(--aa)), var(--cream) 60%,
    var(--cream) calc(80% - var(--aa)), var(--green) 80%);
}
@media (min-resolution: 2dppx) { .rings { --aa: .5px; } }
@media (min-resolution: 3dppx) { .rings { --aa: .34px; } }
```

## 重なりの順番がおかしい

| 症状 | 原因 | 直し方 |
|---|---|---|
| `z-index` が効かない | `position` が `static` | `position: relative` か `absolute` を付ける |
| `z-index: -1` で親の後ろに回らない | 親に `transform`、`opacity`、`clip-path`、`mask`、`filter` などがある | 親からそれらを外す。または部品の構成を変える |
| 内側の影が部品に隠れる | `inset` の影は背景の上、中身の下に描かれる | 影を、手前に置いた別の箱に移す |
| 疑似要素が子要素の下に潜る | `::before` は子要素より奥に描かれる | `::after` を使う。または `z-index` を付ける |

## 切り抜きとマスクが効かない

| 症状 | 原因 | 直し方 |
|---|---|---|
| `shape()` が無視される | ブラウザが未対応 | `polygon()` の近似を先に書く（下の補足） |
| `shape()` の円弧が逆向きに出る | `cw` と `ccw`、`large` の指定 | 半周より長い弧には `large` を付ける |
| `mask` が効かないブラウザがある | 接頭辞が要る古い版 | `-webkit-mask` を併記する。合成は値の名前が違い、`intersect` に当たるのは `-webkit-mask-composite: source-in` |
| 影が消えた | `clip-path` は影も切る | 親に `filter: drop-shadow()` を付ける |
| 子要素まで消えた | `mask` と `clip-path` は子孫にも効く | 切り抜く部品を、子を持たない箱に分ける |
| 多角形がねじれる | 頂点の順番が輪郭に沿っていない | 輪郭を一筆書きでたどる順に並べ直す |

補足:

- **`shape()` の代替**: 先に近似の `polygon()` を書き、対応ブラウザだけ `shape()` に差し替えます

  ```css
  /* まず、どこでも動く近似 */
  .five { clip-path: polygon(/* 円弧を細かい直線で近似した座標 */); }

  /* shape() が使えるブラウザだけ、正確な円弧にする */
  @supports (clip-path: shape(from 0 0, line to 1px 1px, close)) {
    .five { clip-path: shape(from 63% 28%, /* ... */ close); }
  }
  ```

- **円弧の向き**: `cw` は時計回り、`ccw` は反時計回りです。同じ2点を結ぶ円弧は大回りと小回りの2通りあるので、大回りにしたいときは `large` を付けます

## 動きがおかしい

| 症状 | 原因 | 直し方 |
|---|---|---|
| グラデーションがぱっと切り替わる | 背景は途中の値を計算できない | 値を `@property` で登録した変数にする |
| 形がぱっと切り替わる | 頂点の数が違う | 頂点の数をそろえる |
| 形がねじれながら変わる | 頂点の対応がずれている | 開始点と回る向きをそろえる |
| カクつく | 重いプロパティを動かしている | `transform` と `opacity` に置き換える |
| 背景の一部だけ回せない | 背景は箱と一体 | 動かす部品を別の箱に分ける |

それぞれの書き方は `css-art-animate` にあります。

## それでも分からないとき

次の順で、原因を狭めます。

1. **部品を1つずつ消す。** 開発者ツールで要素を非表示にしていき、どの部品が原因か特定する
2. **その部品を赤く塗る。** `background: red !important` を当て、箱の位置と大きさを見る
3. **切り抜きを外す。** `clip-path` と `mask` を消し、箱そのものを見る
4. **方眼を重ねる。** 100×100の方眼を重ね、頂点が座標表どおりの位置にあるか見る
5. **最小の再現を作る。** 問題の部品だけを新しいファイルに写し、余計なものを削る

方眼は次のCSSで重ねられます（10%刻み）。

```css
.art.debug::after {
  content: "";
  position: absolute;
  inset: 0;
  background:
    repeating-linear-gradient(0deg,  rgba(255,255,255,.35) 0 1px, transparent 1px 10%),
    repeating-linear-gradient(90deg, rgba(255,255,255,.35) 0 1px, transparent 1px 10%);
}
```

`::after` をすでに部品に使っている場合は、子要素を1つ足して同じ背景を当てます。

**5番まで行って直らなければ、多くの場合、座標表のほうが間違っています。** 下絵に戻ってください（下絵と座標表の作り方は `css-art-draw`）。
