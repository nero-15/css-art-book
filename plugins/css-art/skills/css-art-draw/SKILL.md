# CSSで絵を描く（設計と実装）

画像もSVGも使わず、CSSだけで絵を描くときの進め方です。出典は書籍『CSSで絵を描く』の1〜5章、7章、付録A。コード例はすべて Chrome 153 で描画を確かめたものです。Safari と Firefox では確認していません。

## 最初に守ること

CSSの絵が崩れる原因は、ほぼ1つです。**座標を決めずに書き始めること**。`top` と `left` を目分量で動かす進め方は、次の理由で終わりません。

- 部品が増えるほど、調整の組み合わせが増える
- 大きさを変えると全部やり直しになる
- 斜めの線が絡むと、目では合わせられない

そのため、コードを書くのは5工程のうち4番目です。先に下絵、部品表、座標表を作ります。そこまで済めば、実装は表の数字を写すだけになります。

題材について。既存のロゴやキャラクターなど権利のある図柄は公開できません。練習や作例は、利用者自身のサイトや架空のブランドを題材にすることを勧めます。

## 用語

| 用語 | 意味 |
|---|---|
| 箱 | 1つの要素、または疑似要素が占める長方形 |
| 部品 | 絵を構成する1つの形。1つの箱で描けるとは限らない |
| ハードストップ | グラデーションで、ぼかさずに色を切り替えること |
| single-div | 子要素を使わず、要素1つと疑似要素だけで描く流儀 |
| 画面密度 | 1 CSSピクセルを何個の物理ピクセルで描くか。スマホやRetina画面では2〜3 |

## 5つの工程

| 工程 | やること | 成果物 |
|---|---|---|
| 1 下絵 | 絵を決め、方眼に載せる | 方眼つきの下絵 |
| 2 分解 | 絵を部品に分け、部品ごとに道具を決める | 部品表 |
| 3 座標 | 各部品の頂点・中心・半径を数値にする | 座標表 |
| 4 実装 | 大きい形から順にCSSにする | コード |
| 5 検証 | 拡縮と他ブラウザで崩れないか見る | スクリーンショット |

### 工程1 下絵を方眼に載せる

- **100×100の方眼**を使う。左上が (0, 0)、右下が (100, 100)
- この座標系は CSS の `%` とそのまま対応する。方眼の (35, 40) は CSS で `35% 40%`。換算が要らない
- **線の太さ、文字の高さ、円の中心と半径を、きりのいい数字で先に決める**。例: 文字の高さは y ＝ 28 から 72 まで（44）、線の太さは 7、円の中心 (69, 58)、外側の半径 14、内側の半径 7。先に決めると座標がきれいな数字になる

エージェントとして描く場合は、下絵の代わりに「方眼上のどこに何を置くか」を文章と数値で書き出してから先へ進みます。

### 工程2 部品に分け、道具を決める

絵を「1色で塗れる、ひとかたまりの形」に分けます。山と太陽のバッジなら、空、太陽、山、雪、縁の5部品です。

部品ごとに、次の表を**上から順に見て、最初に当てはまったもの**を使います。

| 部品の形 | 使う道具 |
|---|---|
| 長方形、角丸、円、楕円 | `width` / `height` と `border-radius` |
| 輪、同心円、縞、扇形、水玉 | グラデーションの背景 |
| 直線だけで囲まれた形 | `clip-path: polygon()` |
| 直線と円弧で囲まれた形 | `clip-path: shape()` |
| 穴の開いた形、欠けた輪 | `mask` |
| 同じ小さな形の繰り返し（ドット絵） | `box-shadow` を並べる |
| どれにも当てはまらない | さらに細かく分ける |

迷ったら `clip-path: polygon()` を選びます。直線で近似できる形なら、ほぼ何でも描けます。

部品表は「部品名、色、形、使う道具」の列で作ります。

**箱の数を見積もる。** 要素1つにつき、箱は3つ使えます。要素自身、`::before`、`::after` です。背景は何枚でも重ねられるので、グラデーションで描ける部品は箱を消費しません。足りないときは子要素を足します。無理に減らす必要はありません。

### 工程3 頂点を数値にする

部品ごとに、頂点・中心・半径を表にします。列は「番号、座標、決め方」です。

- ほとんどの頂点は下絵から読むだけ
- **斜めの線と縦横の線の交点、円弧の端点は、目分量にせず計算する**。式は [references/formulas.md](references/formulas.md)
- 円弧を含む輪郭は、たどる向きを1つ決めて点を順に並べる（実例は左上から時計回り）。`shape()` の `cw` / `ccw` はその向きに合わせる

座標表ができたら、CSSは表を左から写すだけです。

```css
.n {
  clip-path: polygon(
    17% 72%, 17% 28%, 25% 28%, 38% 56.6%, 38% 28%,
    45% 28%, 45% 72%, 37% 72%, 24% 43.4%, 24% 72%);
}
```

この例の `56.6` と `43.4` が計算した交点です。残り8点は下絵から読んでいます。

### 工程4 大きい形から積む

実装の順番は、**奥から手前、大から小**です。背景の円、次に大きな面、最後に細部。途中のどの段階でも「絵として見られる状態」になり、ずれに早く気づけます。

**部品を載せる箱は、すべて親と同じ大きさにします。**

```css
.art > * {
  position: absolute;
  inset: 0;
}
```

箱の位置は全部同じにして、形は `clip-path` で切ります。`top` や `left` を考える必要が無くなり、座標表の数字をそのまま使えます。疑似要素も同じです（`content: ""; position: absolute; inset: 0;`）。

例外は、グラデーションと `mask` で描く円形の部品（欠けた輪など）です。これは箱そのものを円の外接正方形にします。中心 (69, 58)、半径14の円なら、左端は 69 − 14 ＝ 55、上端は 58 − 14 ＝ 44、幅と高さは28。`inset: auto; left: 55%; top: 44%; width: 28%; height: 28%;` と書きます。

### 工程5 検証する

最低限、次の3つを確かめます。

- 大きさを 24px、100px、400px に変えて崩れないか
- 下絵と重ねてずれが無いか（下絵を半透明にして背面に置く）
- 方眼を重ねて、頂点が狙った位置にあるか

方眼は次のCSSで重ねられます。

```css
.art.debug::after {
  content: "";
  position: absolute;
  inset: 0;
  background:
    repeating-linear-gradient(0deg,  rgba(255,255,255,.35) 0 1px, transparent 1px 10%),
    repeating-linear-gradient(90deg, rgba(255,255,255,.35) 0 1px, transparent 1px 10%);
}
```

`::after` をすでに部品に使っている場合は、子要素を1つ足して同じ背景を当てます。

**曲線と直線の接合部は、計算だけで済ませず拡大して目で見ます。** 計算が合っていても、輪の外周が隣の直線部品からはみ出して小さな出っ張りになることがあります（実例は [references/worked-example.md](references/worked-example.md)）。

縁のギザギザ、継ぎ目の隙間、画面密度ごとの確認、新しい機能の代替、複数ブラウザでの確認は、スキル `css-art-quality` の担当です。崩れたときの原因探しは `css-art-troubleshoot` を使います。下絵の画像があるときは、スキル `css-art-verify` のスクリプトで、下絵を測る・描画する・画素で突き合わせるを、合格するまで繰り返せます。

## 道具選びの要点

詳しい書き方とコードは [references/toolbox.md](references/toolbox.md) にあります。ここは判断の早見です。

### 基本の3動作

CSSの絵は、ほぼこの3つの組み合わせです。

| 動作 | 使うもの | 向いている形 |
|---|---|---|
| 背景で描く | `radial-gradient` など | 円、輪、縞、扇形 |
| 切り抜いて描く | `clip-path: polygon()` | 直線で囲まれた形 |
| 重ねて描く | `::before` と `::after` | 色の違う部品 |

### 色を置く道具（箱を増やさない）

| 描きたいもの | 第一候補 | 理由 |
|---|---|---|
| 円、楕円、角丸 | `border-radius` | 縁が最もきれい |
| 輪を1〜2本 | `radial-gradient` | 箱を増やさない |
| 輪を外側に足す | `box-shadow` の広がり | 書くのが楽 |
| 縞、水玉、市松 | グラデーション＋`background-size` | 繰り返しに強い |
| 扇形、放射状 | `conic-gradient` | 角度で指定できる |
| 同じ形の複製 | `box-shadow` | 何個でも並べられる |

グラデーションの選び方は、円や輪なら `radial-gradient`、角度で区切りたいなら `conic-gradient`、同じ模様の繰り返しなら `repeating-` を頭に付けるか `background-size` でタイルにします。

### 消す道具（clip-path と mask）

| 条件 | 使うもの |
|---|---|
| 輪郭が一筆書きで描ける | `clip-path` |
| 穴が開いている | `mask` |
| 縁をぼかしたい、だんだん消したい | `mask` |
| 形を動かしたい | `clip-path`（頂点数が同じ `polygon()` 同士は補間できる） |
| 縁を最もきれいにしたい | `clip-path` |
| 切り抜いた形に影を付けたい | どちらも直接は不可。親要素に `filter: drop-shadow()` |

迷ったら `clip-path` から試します。書くのが楽で、縁の品質も安定しています。

### 外しやすい点

- グラデーションの背景は、透明を指定しない限り箱全体を塗る。複数の形を重ねるときは、形の外側を必ず `transparent` にする
- `radial-gradient` には `closest-side` を付ける。付けないと100%が最も遠い角までの距離になり、「半径の何%」と合わない
- 背景も `box-shadow` も、カンマで並べると**先に書いたものが手前**
- `clip-path` を付けると `box-shadow` も一緒に消える。1つの箱に輪郭は1つだけ
- 子要素を持つ要素に `mask` をかけると、子要素まで消える。その場合は背景の重ねで同じ形を作る
- `shape()` は新しい機能（Chrome 135、Safari 18.4、Firefox 148 から）。古いブラウザでは切り抜きが効かず、箱がそのまま表示される。代替の書き方は `css-art-quality`
- `path()` は px 固定で拡縮しない。絵には `shape()` を使う
- `shape()` の円弧が半周より長いときは `large` を付ける。付け忘れると短いほうの弧が引かれ、形が壊れる
- `transform`、`opacity`、`filter`、`mask`、`clip-path` などを指定した要素は、中の重なり順が外と切り離される。部品が思った順に重ならないときは、まずこれを疑う
- 枠線で作る三角形（幅と高さ0の箱）は古い手法。新しく書くなら `clip-path` を使う

## 構成の選び方（子要素あり / shape() / single-div）

同じ絵でも、制約を変えると使う道具が変わります。紋章「N15」を3通りで描いた結果です（[references/worked-example.md](references/worked-example.md)）。

| 版 | 子要素 | 対応ブラウザ | 向く用途 |
|---|---|---|---|
| 基本版（部品ごとに子要素） | 4 | 広い | 学習。部品ごとに色や動きを変えたいとき |
| shape() 版 | 3 | 2026年2月以降の主要ブラウザ | コードを短く、正確にしたいとき |
| single-div 版 | 0 | 広い | HTMLを汚したくないとき。ロゴやファビコンの元絵 |

選び方は次のとおりです。

- **指定が無ければ、まず基本版で作る。** いちばん素直な構成で、部品ごとに直しやすい（本の決まりではなく、この skill の方針）
- **直線と円弧が混ざる部品**は、`shape()` で1本の輪郭にまとめられる。`mask` も `conic-gradient` も要らなくなり、縁の品質が `clip-path` に統一される。ただし対応ブラウザが新しい
- **実際にサイトへ置くなら single-div 版を勧める。** HTMLが `div` 1つで済み、意味のない空要素が増えない。`polygon()` だけなので古いブラウザでも動く
- single-div で箱が足りないときは、同じ色の離れた形を**幅ゼロの橋**でつないで1つの `polygon()` にする。円弧は約6度刻みの点で**多角形に近似**する。座標は手で書かず、スクリプトで生成する（[references/recipes.md](references/recipes.md) の5.11、[references/worked-example.md](references/worked-example.md)）
- 部品ごとに動かしたいなら子要素を残す。動きの付け方は `css-art-animate`

そもそもCSSで描くべきか（SVGや画像、canvasとの使い分け）、アクセシビリティ、強制カラー、画像への書き出しは `css-art-production` の担当です。数千マスのドット絵のように重くなるものは、そちらで使い分けを確かめてください。

## コードの約束

- 色は CSS変数にまとめる（例: `--green: #0f3d2e; --cream: #f4ecd8; --red: #e4572e;`）
- 座標は原則 `%` で書く。px で書くと拡縮できなくなる
- 大きさの基準は変数1つ（`--size`）にまとめ、ルートに `width: var(--size); aspect-ratio: 1;` を付ける
- 枠線を使うときは `box-sizing: border-box` を付ける。付けないと枠線の分だけ全体が大きくなる

## よくある失敗

| 失敗 | 対策 |
|---|---|
| 何も表示されない | `width` を指定する。空の `div` は高さが0 |
| 疑似要素の部品が出ない | `content: ""` を書く。無いと疑似要素は生成されない |
| 部品が円からはみ出す、画面の左上に出る | ルートに `overflow: hidden`、`position: relative` を付ける |
| 下絵なしで書き始める | 方眼に載せてから始める |
| pxで座標を書く | `%` で書く |
| 斜めの帯を `rotate` で回して置く | 位置合わせが難しく、継ぎ目に隙間が出る。`polygon()` で描く |
| 細部から作り始める | 大きい形から。全体の釣り合いを先に確かめる |
| 縦棒と斜めの帯を別々の部品にする | 文字のような形は全体を1つの `polygon()` にする |
