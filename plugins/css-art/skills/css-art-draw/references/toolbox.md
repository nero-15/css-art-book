# 道具箱: どのCSS機能で何が描けるか

出典: 『CSSで絵を描く』3章（箱・角丸・グラデーション・影）、4章（切り抜きとマスク）。コードは Chrome 153 で描画を確かめたものです。

色は次の変数を使います。

```css
:root { --green: #0f3d2e; --cream: #f4ecd8; --red: #e4572e; }
```

## 目次

1. 箱と角丸
2. グラデーションで描く
3. 影で描く
4. 枠線で描く三角形
5. clip-path: 輪郭で切り抜く
6. mask: 濃淡で消す
7. clip-path と mask のどちらを使うか
8. 変形と重なり
9. 道具の選び方まとめ

1〜4は「色を置く」道具で、**箱を増やさずに描ける**のが強みです。5〜6は「要らない部分を消す」道具で、箱をいったん塗りつぶし、残したい形だけを残します。

## 1. 箱と角丸

長方形は `width` と `height`、色は `background`。絵では `border-radius` の使い方が広がります。

| 書き方 | 結果 |
|---|---|
| `border-radius: 50%` | 正方形なら円、長方形なら楕円 |
| `border-radius: 10px` | 四隅が同じ丸み |
| `border-radius: 0 50% 50% 50%` | 左上だけ尖る。45度回すとしずく |
| `border-radius: 50% 50% 50% 50% / 60% 60% 40% 40%` | 上が細く下が太い。卵 |

4つ目の書き方が要点です。スラッシュの前が各角の**横方向**の半径、後ろが**縦方向**の半径です。左上、右上、右下、左下の順に4つずつ、合計8つの値で、角ごとに楕円の丸みを指定できます。有機的な絵は、この8値の角丸を大量に重ねて作られます。

```css
.egg  { border-radius: 50% 50% 50% 50% / 60% 60% 40% 40%; }
.drop { border-radius: 0 50% 50% 50%; transform: rotate(45deg); }
```

## 2. グラデーションで描く

絵を描くときは、グラデーションを**ぼかさずに使います**。同じ位置で色を切り替えると、境界のはっきりした形になります（ハードストップ）。

### 3種類のグラデーション

| 関数 | 色が変わる向き | 描けるもの |
|---|---|---|
| `linear-gradient` | 直線に沿って | 帯、縞、斜めの塗り分け |
| `radial-gradient` | 中心から外へ | 円、輪、同心円、水玉 |
| `conic-gradient` | 中心のまわりを回って | 扇形、円グラフ、市松、放射 |

どれも要素1つ、子要素なしで描けます。

```css
/* ハードストップ: 50%の位置で色を切り替える */
.g1 { background: linear-gradient(90deg, var(--red) 50%, var(--cream) 50%); }

/* 輪: 55%〜80%だけ色を付ける */
.g2 { background: radial-gradient(closest-side,
        transparent 55%, var(--green) 55% 80%, transparent 80%); }

/* 扇形: 120度ずつ3色 */
.g3 { border-radius: 50%;
      background: conic-gradient(var(--red) 0 120deg,
        var(--cream) 120deg 240deg, var(--green) 240deg); }

/* 縞: 20pxごとに繰り返す */
.g4 { background: repeating-linear-gradient(45deg,
        var(--green) 0 10px, var(--cream) 10px 20px); }

/* 水玉: 小さな円を25%角のタイルにして敷き詰める */
.g5 { background:
        radial-gradient(circle, var(--red) 30%, transparent 31%) 0 0 / 25% 25%,
        var(--cream); }

/* 市松: 4分割の扇形を50%角のタイルにする */
.g6 { background: conic-gradient(var(--green) 25%, var(--cream) 0 50%,
        var(--green) 0 75%, var(--cream) 0) 0 0 / 50% 50%; }
```

ぼかしのない円を1つ置く例（背景を重ね、先に書いたものが手前）。`circle at 70% 30%` が中心の位置です。

```css
.badge {
  background:
    radial-gradient(circle at 70% 30%, #ffd166 0 12%, transparent 12.5%),
    #bfe3f2;
}
```

### 覚えておく書き方

**色の後ろに位置を2つ書ける。** `var(--green) 55% 80%` は「55%から80%まで緑」という意味です。

**`closest-side` を付ける。** `radial-gradient` の100%は、既定では中心から最も遠い**角**までの距離です。正方形の箱なら、辺までの約1.41倍になります。`closest-side` を付けると100%が辺までの距離になり、「半径の何%」という直感どおりに書けます。

**位置に0を書くと「直前と同じ位置」になる。** 市松の `var(--cream) 0 50%` の0は、前の色の終わり（25%）に繰り上がります。

**背景は重ねられ、大きさと位置を個別に決められる。** `背景 位置 / 大きさ` の順に書きます。水玉の `0 0 / 25% 25%` は「左上から、25%角のタイルで」という意味です。繰り返したくないときは `no-repeat` を足します。カンマで区切ると背景を重ねられ、**先に書いたものが手前**です。

> **注意**
> グラデーションの背景は、透明を指定しない限り箱全体を塗ります。複数の形を重ねるときは、形の外側を必ず `transparent` にしてください。

### どれを使うか迷ったら

- 円や輪 → `radial-gradient`
- 角度で区切りたい → `conic-gradient`
- 同じ模様の繰り返し → `repeating-` を頭に付けるか、`background-size` でタイルにする

`conic-gradient` の角度は真上が0度で、時計回りに増えます。始まりを変えるには `from 45deg` のように書きます。

グラデーションで描いた円や輪は縁がギザつきやすいので、スキル `css-art-quality` の対策を入れてください。

## 3. 影で描く

`box-shadow` は、箱と同じ形の複製を、ずらして描く機能です。絵では「影」ではなく**複製の道具**として使います。

書式は `横のずれ 縦のずれ ぼかし 広がり 色` です。絵ではぼかしを0にします。

### 同心リング: 広がりを重ねる

```css
.rings {
  width: 50px; height: 50px;
  border-radius: 50%;
  background: var(--red);
  box-shadow:
    0 0 0 10px var(--cream),
    0 0 0 20px var(--green),
    0 0 0 30px var(--red);
}
```

4番目の値（広がり）を大きくすると、箱より大きい複製になります。カンマで並べると重なり、**先に書いたものが手前**です。小さい順に書けば同心円になります。

影は箱の外にはみ出して描かれ、レイアウト上の大きさには含まれません。周囲に余白を取ってください。

### 三日月: 内側の影をずらす

```css
.moon {
  width: 70px; height: 70px;
  border-radius: 50%;
  box-shadow: inset 22px -8px 0 0 #f2b705;
}
```

`inset` を付けると影が箱の内側に描かれます。ずらした分だけ縁に色が残り、三日月になります。背景は指定しません。

### ドット絵: 1マスを影1つで描く

1マス分の小さな箱を1つ用意し、影を必要な数だけ並べます。

```css
.heart {
  width: 1em; height: 1em;       /* 1マスの大きさ */
  font-size: 16px;               /* ここを変えると全体が拡縮する */
  box-shadow:
    1em 0 0 #e4572e, 2em 0 0 #e4572e, 4em 0 0 #e4572e, 5em 0 0 #e4572e,
    0 1em 0 #e4572e, 1em 1em 0 #e4572e, 2em 1em 0 #e4572e, /* ... */
    3em 5em 0 #e4572e;
}
```

ずれを `em` で書くのがこつです。pxだと大きさを変えるたびに全部書き直しになります。`em` なら `font-size` を変えるだけです。

手で書く量ではないので、マス目のデータからスクリプトで生成します。

```js
const rows = ["0110110", "1111111", "1111111", "0111110", "0011100", "0001000"];
const shadows = rows.flatMap((row, y) =>
  [...row].map((c, x) => c === "1" ? `${x}em ${y}em 0 #e4572e` : null)
).filter(Boolean).join(", ");
```

> **注意**
> 影はマスの数だけ描画されます。数百マスなら問題になりませんが、数千マスを動かすと重くなります。大きなドット絵は、スキル `css-art-production` の使い分けを見て、canvasや画像を検討してください。

## 4. 枠線で描く三角形

古くからある手法です。幅と高さを0にした箱に太い枠線を付けると、4辺の枠線がそれぞれ三角形になります。1辺だけ色を付け、隣の2辺を透明にすると三角形が残ります。

```css
.triangle {
  width: 0; height: 0;
  border-left: 45px solid transparent;
  border-right: 45px solid transparent;
  border-bottom: 80px solid var(--green);
}
```

今は `clip-path: polygon()` のほうが素直に書けます。枠線の三角形には影やグラデーションを付けられない、という制約もあります。古いコードを読むために知っておけば十分です。

## 5. clip-path: 輪郭で切り抜く

`clip-path` は、指定した輪郭の内側だけを表示します。外側は描画されず、クリックにも反応しません。

| 関数 | 描ける輪郭 | 使いどころ |
|---|---|---|
| `inset()` | 長方形。`round` で角丸 | 縁を一定幅だけ削る |
| `circle()` | 円 | 中心と半径で指定したい円 |
| `ellipse()` | 楕円 | 同上 |
| `polygon()` | 直線で結んだ多角形 | **最もよく使う** |
| `shape()` | 直線と曲線を混ぜた輪郭 | 円弧を含む形 |
| `path()` | SVGのパス文字列 | 拡縮しない固定サイズの形 |

```css
.c1 { clip-path: inset(10% round 20%); }
.c2 { clip-path: circle(40%); }
.c3 { clip-path: ellipse(50% 30%); }
.c4 { clip-path: polygon(50% 5%, 95% 95%, 5% 95%); }
.c5 { clip-path: polygon(50% 0%, 61% 35%, 98% 35%, 68% 57%, 79% 91%,
                         50% 70%, 21% 91%, 32% 57%, 2% 35%, 39% 35%); }
.c6 { clip-path: shape(from 50% 0%,
        arc to 50% 100% of 50% cw,
        arc to 50% 0% of 80% cw, close); }
```

`.c4` は三角形、`.c5` は10頂点の星、`.c6` は円弧2本の輪郭です。

### polygon() の書き方

頂点を `x y` の組で並べ、カンマで区切ります。座標は「左から何%、上から何%」です。最後の点と最初の点は自動で結ばれます。

- 時計回りでも反時計回りでも結果は同じ
- 単位は `%` を使う。箱の大きさが変わっても形が保たれる
- `calc()` も使える。`calc(100% - 10px)` で「右端から10px内側」

座標表は、そのまま `polygon()` に写せます。

### shape() の書き方

`shape()` は、`polygon()` に曲線を足したものです。ペンを動かす命令を順に書きます。

| 命令 | 意味 |
|---|---|
| `from X Y` | 開始点 |
| `line to X Y` | 直線を引く |
| `arc to X Y of R` | 半径Rの円弧を引く |
| `curve to X Y with CX CY` | 制御点つきの曲線を引く |
| `move to X Y` | 輪郭を分ける。離れた形を1つの箱で描くとき、橋の代わりに使える |
| `close` | 開始点まで戻って閉じる |

円弧には回る向きと大きさの指定が付きます。`cw` は時計回り、`ccw` は反時計回り。同じ2点を結ぶ円弧は大回りと小回りの2通りあるので、大回りにしたいときは `large` を付けます。半周より長い円弧で `large` を付け忘れると、短いほうの弧が引かれ、形が壊れます。

`path()` との違いは単位です。`path()` はpx固定で、箱を拡縮しても形が変わりません。`shape()` は座標ごとに `%` や `calc()` を使えます。絵を描くなら `shape()` を選んでください。

> **注意**
> `shape()` は新しい機能です。Chrome 135、Safari 18.4、Firefox 148 から使えます。古いブラウザでは切り抜きが効かず、箱がそのまま表示されます。対応状況の確かめ方と代替手段は、スキル `css-art-quality` で扱います。

### clip-path の制約

- 切り抜いた外側には何も描けない。影（`box-shadow`）も一緒に消える
- 穴の開いた形は苦手。輪郭を一筆書きで描く必要がある
- 1つの箱に1つの輪郭しか指定できない

2つ目と3つ目の制約を超えたいときに、`mask` を使います。

## 6. mask: 濃淡で消す

`mask` は、別の画像の**不透明な部分だけ**を残す機能です。画像にはグラデーションを使えます。つまり、グラデーションの描き方が、そのまま「消し方」になります。

マスクの黒（不透明）の部分が残り、透明の部分が消えます。色は何でも構いません。慣習として残す部分を `#000`、消す部分を `#0000`（透明）と書きます。

### 輪: 中心を抜く

```css
.ring {
  background: var(--red);
  mask: radial-gradient(closest-side, #0000 60%, #000 61% 100%, #0000 0);
}
```

中心から60%までを消し、61%〜100%を残し、その外を消します。グラデーションの輪は「輪に色を塗る」方法、こちらは「塗った箱を輪の形に抜く」方法です。背景に模様やグラデーションを使いたいときは、マスクのほうが向いています。

### 弧: 2枚のマスクの重なりだけ残す

```css
.arc {
  border-radius: 50%;
  background: var(--red);
  mask:
    radial-gradient(closest-side, #0000 60%, #000 61%),
    conic-gradient(#000 0 270deg, #0000 0);
  mask-composite: intersect;
}
```

マスクを2枚重ね、`mask-composite: intersect` で「両方が不透明な部分だけ」を残します。1枚目が輪、2枚目が270度の扇形なので、重なりは4分の3周の弧になります。

`mask-composite` の値は4つあります。

| 値 | 残る部分 |
|---|---|
| `add`（既定） | どちらかが不透明な部分 |
| `subtract` | 1枚目から2枚目を引いた部分 |
| `intersect` | 両方が不透明な部分 |
| `exclude` | 片方だけが不透明な部分 |

### 切り欠き: 左右に半円の欠けを作る

```css
.ticket {
  background: var(--red);
  mask:
    radial-gradient(circle 14px at 0 50%, #0000 97%, #000) 0 0 / 51% 100% no-repeat,
    radial-gradient(circle 14px at 100% 50%, #0000 97%, #000) 100% 0 / 51% 100% no-repeat;
}
```

左半分と右半分に1枚ずつマスクを置き、それぞれの外側の辺に半円の穴を開けています。幅を `51%` にして1%重ねているのは、中央に隙間が出るのを防ぐためです（隙間の対策は `css-art-quality`）。

### ぼかして消す

```css
.fade { mask: linear-gradient(#000, #0000); }
```

グラデーションをぼかしたまま使えば、だんだん消える表現になります。`clip-path` にはできないことです。

### mask の注意

- 古いブラウザ向けには `-webkit-mask` の併記が必要です。`mask-image` が主要ブラウザで接頭辞なしに使えるようになったのは2023年12月です。合成の指定は接頭辞つきだと値の名前が違い、`intersect` に当たるのは `-webkit-mask-composite: source-in` です
- 子要素を持つ要素に `mask` をかけると、子要素まで消えます。親の背景を輪に抜きたいときは、`mask` の代わりに背景を2枚重ねます（奥に模様、手前に「輪の部分だけ透明な地の色」）。実例は [worked-example.md](worked-example.md) の破線リング

## 7. clip-path と mask のどちらを使うか

| 条件 | 使うもの |
|---|---|
| 輪郭が一筆書きで描ける | `clip-path` |
| 穴が開いている | `mask` |
| 縁をぼかしたい、だんだん消したい | `mask` |
| 形を動かしたい | `clip-path`（頂点数が同じ `polygon()` 同士は補間できる） |
| 縁を最もきれいにしたい | `clip-path` |
| 切り抜いた形に影を付けたい | どちらも直接は不可。親要素に `filter: drop-shadow()` |

迷ったら `clip-path` から試します。書くのが楽で、縁の品質も安定しています。

## 8. 変形と重なり

切り抜いた部品は、`transform` で回したり傾けたりできます。

| 関数 | 効果 | 絵での使い道 |
|---|---|---|
| `rotate(45deg)` | 回す | しずく、ひし形 |
| `skewX(-20deg)` | 斜めにゆがめる | 平行四辺形 |
| `scale(-1, 1)` | 左右反転 | 左右対称の部品を使い回す |
| `translate(10%, 0)` | ずらす | 微調整 |

回転の中心は `transform-origin` で変えられます。既定は箱の中央です。

斜めの帯を `rotate` で回して置くのは勧めません。位置合わせが難しく、継ぎ目に隙間が出ます。`polygon()` で描きます。

重なりの順番は、後に書いた要素が手前です。`::before` は子要素より奥、`::after` は子要素より手前に描かれます。変えたいときは `z-index` を使いますが、`transform`、`opacity`、`filter`、`mask`、`clip-path` などを指定した要素は、中の重なり順が外と切り離されます。部品の中の部品が思った順に重ならないときは、まずこれを疑ってください。

## 9. 道具の選び方まとめ

部品の形から道具を決める表（上から順に見て、最初に当てはまったものを使う）。

| 部品の形 | 使う道具 |
|---|---|
| 長方形、角丸、円、楕円 | `width` / `height` と `border-radius` |
| 輪、同心円、縞、扇形、水玉 | グラデーションの背景 |
| 直線だけで囲まれた形 | `clip-path: polygon()` |
| 直線と円弧で囲まれた形 | `clip-path: shape()` |
| 穴の開いた形、欠けた輪 | `mask` |
| 同じ小さな形の繰り返し（ドット絵） | `box-shadow` を並べる |
| どれにも当てはまらない | さらに細かく分ける |

色を置く道具の第一候補。

| 描きたいもの | 第一候補 | 理由 |
|---|---|---|
| 円、楕円、角丸 | `border-radius` | 縁が最もきれい |
| 輪を1〜2本 | `radial-gradient` | 箱を増やさない |
| 輪を外側に足す | `box-shadow` の広がり | 書くのが楽 |
| 縞、水玉、市松 | グラデーション＋`background-size` | 繰り返しに強い |
| 扇形、放射状 | `conic-gradient` | 角度で指定できる |
| 同じ形の複製 | `box-shadow` | 何個でも並べられる |
