# 計算式: 座標を目分量にしないために

出典: 『CSSで絵を描く』付録A（計算式）、2章、5章、7章。

座標系は100×100の方眼です。左上が (0, 0)、右下が (100, 100)。方眼の数値はそのまま CSS の `%` になります。角度は**真上が0度、時計回り**です（`conic-gradient` の角度と同じ向き）。

## 一覧

| 求めたいもの | 式 |
|---|---|
| 斜めの線の傾き | 縦の変化 ÷ 横の変化 |
| 斜めの線の上の点 | y ＝ 起点のy ＋ 起点からの横の距離 × 傾き |
| 円周上の点（真上が0度、時計回り） | x ＝ cx ＋ r × sin θ、y ＝ cy − r × cos θ |
| 円と縦線の交点 | y ＝ cy ± √(r² − (x − cx)²) |
| 円と横線の交点 | x ＝ cx ± √(r² − (y − cy)²) |
| 正n角形のk番目の頂点 | 円周上の点の式で、θ ＝ 360° ÷ n × k |
| CSSの角度 → canvasの角度 | 90度引く |

計算が面倒なら、表計算ソフトに式を1つ入れるか、スクリプトで出します。

## 斜めの線の上の点

斜めの線と縦の線が交わる点は、一次関数で求めます。例は文字「N」の斜めの帯と右の縦棒の交点です。

1. 斜めの線の両端を決める。帯の上側の辺は (25, 28) から (45, 72) へ引いた線
2. 傾きを出す。縦の変化 ÷ 横の変化 ＝ (72 − 28) ÷ (45 − 25) ＝ **2.2**
3. 求めたい点の x を入れる。x ＝ 38 なので、起点から横に 13 進んだ位置
4. y ＝ 28 ＋ 13 × 2.2 ＝ **56.6**

帯の下側の辺も同じです。(17, 28) から (37, 72) で、傾きは同じ2.2。x ＝ 24 は起点から横に7なので、y ＝ 28 ＋ 7 × 2.2 ＝ **43.4**。

y から x を逆算することもできます。山の左の斜面が (0, 100) から (35, 40) のとき、y ＝ 54 になる x は **26.8** です（斜面の上に雪の縁をぴったり乗せるための値）。

## 円周上の点

中心 (cx, cy)、半径 r、角度 θ から求めます。

- x ＝ cx ＋ r × sin θ
- y ＝ cy − r × cos θ

例: 中心 (69, 58)、半径14の円の232度の位置。

- x ＝ 69 ＋ 14 × sin 232° ＝ **57.97**
- y ＝ 58 − 14 × cos 232° ＝ **66.62**

同じ中心で半径7なら (63.48, 62.31) です。

CSSの中で直接計算することもできます。次は、要素を円周上に等間隔で置く書き方です（`--i` が何番目か、`30deg` が1つあたりの角度、`40%` が半径）。

```css
--a: calc(var(--i) * 30deg);
left: calc(50% + sin(var(--a)) * 40%);
top:  calc(50% - cos(var(--a)) * 40%);
```

## 円と直線の交点（円弧の端点）

円弧が縦線や横線とぶつかる点は、三平方の定理で求めます。

**円と縦線の交点:** y ＝ cy ± √(r² − (x − cx)²)

例: 中心 (69, 58)、半径14の円と、縦線 x ＝ 70。中心から横に1ずれた位置なので、√(14² − 1²) ≒ 13.96。上側の交点は y ＝ 58 − 13.96 ＝ **44.04**。

**円と横線の交点:** x ＝ cx ± √(r² − (y − cy)²)

例: 中心 (69, 58)、半径7の円と、横線 y ＝ 52。中心から縦に6ずれた位置なので、√(7² − 6²) ≒ 3.61。左側の交点は x ＝ 69 − 3.61 ＝ **65.39**。

交点の角度が要るときは、逆三角関数で出します。半径 R の円が、中心から横に1ずれた縦線と交わる角度は次のとおりです。

```js
const a0 = Math.asin(1 / R) * 180 / Math.PI;     // 外周が x=70 と交わる角度
```

## 正多角形と星の頂点

正n角形の k 番目の頂点（箱いっぱいに描く場合。真上から始めて時計回り）。

- x ＝ 50 ＋ 50 × sin(360° ÷ n × k)
- y ＝ 50 − 50 × cos(360° ÷ n × k)

```js
const n = 5;
const pts = [...Array(n)].map((_, k) => {
  const a = (2 * Math.PI / n) * k;
  return `${(50 + 50 * Math.sin(a)).toFixed(2)}% ${(50 - 50 * Math.cos(a)).toFixed(2)}%`;
});
console.log(pts.join(", "));
```

正五角形の結果は `50% 0%, 97.55% 34.55%, 79.39% 90.45%, 20.61% 90.45%, 2.45% 34.55%` です。

星は、頂点数を2倍にし、奇数番目だけ半径を小さく（外側の約40%に）します。

## 円弧を多角形で近似する

`polygon()` だけで円弧を描くときは、円弧を約6度刻みの点で近似します。点は円周上の点の式で生成します。

```js
const cx = 69, cy = 58, R = 14, r = 7;
const pt = (rad, deg) => {
  const a = deg * Math.PI / 180;
  return [cx + rad * Math.sin(a), cy - rad * Math.cos(a)];
};
```

これを使った全体のスクリプトは [worked-example.md](worked-example.md) の single-div 版にあります。約6度刻みの近似は、360pxに拡大しても角が見えませんでした（Chrome 153）。

## 箱の位置と大きさ（円形の部品）

グラデーションや `mask` で描く円形の部品は、箱を円の外接正方形にします。中心 (cx, cy)、半径 r のとき、

- 左端 ＝ cx − r、上端 ＝ cy − r
- 幅と高さ ＝ 2 × r

例: 中心 (69, 58)、半径14 → `left: 55%; top: 44%; width: 28%; height: 28%;`

## 繰り返しの周期

- 破線の輪の1周期 ＝ 360 ÷ 本数。12本なら30度、15本なら24度
- 円周上に等間隔で並べるときの1つあたりの角度 ＝ 360 ÷ 個数。12個なら30度

## 角度の向きの違い

CSSの角度（`conic-gradient` など）は真上が0度です。canvas に移すときは90度引きます。canvas への書き出しはスキル `css-art-production` で扱います。
