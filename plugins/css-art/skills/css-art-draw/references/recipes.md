# レシピ集: 「この形はどう描く？」

出典: 『CSSで絵を描く』5章。各レシピは**問題・解決・解説**の順で、単独で読めます。コードは Chrome 153 で描画を確かめたものです。

色は次の変数を使います。

```css
:root { --green: #0f3d2e; --cream: #f4ecd8; --red: #e4572e; }
```

| 番号 | 描きたいもの | 主な道具 |
|---|---|---|
| 5.1 | 輪 | radial-gradient / box-shadow / border |
| 5.2 | 破線の輪 | repeating-conic-gradient ＋ mask |
| 5.3 | 三角形 | clip-path |
| 5.4 | 斜めの帯 | clip-path |
| 5.5 | 平行四辺形 | clip-path / skew |
| 5.6 | 欠けた輪（弧） | conic-gradient ＋ mask |
| 5.7 | 三日月 | box-shadow inset |
| 5.8 | 正多角形と星 | clip-path ＋ 頂点の計算 |
| 5.9 | しずくと卵 | border-radius |
| 5.10 | 円周上に並べる | sin() / cos() |
| 5.11 | 離れた形を1つの箱で描く | polygon の橋 |

## 5.1 輪を描く

### 問題

中が抜けた円（輪）を描きたい。

### 解決

箱を増やしたくないなら `radial-gradient` を使います。

```css
.ring {
  width: 110px; aspect-ratio: 1;
  background: radial-gradient(closest-side,
    transparent 55%, var(--green) 55% 80%, transparent 80%);
}
```

### 解説

輪の描き方は3つあり、それぞれ得意な場面が違います。

| 方法 | コード | 向く場面 |
|---|---|---|
| 枠線 | `border: 10px solid; border-radius: 50%` | 輪が1本だけ。縁が最もきれい |
| 影 | `box-shadow: 0 0 0 10px` | 円の外側に輪を足したい |
| グラデーション | 上記 | 何本も描きたい。他の背景と重ねたい |

迷ったら、1本なら枠線、複数ならグラデーションです。

**落とし穴:** グラデーションの輪は縁がギザつきやすい。スキル `css-art-quality` の対策を入れてください。

## 5.2 破線の輪を描く

### 問題

等間隔に切れ目の入った輪を描きたい。時計の目盛りや紋章の縁飾りに使う。

### 解決

`repeating-conic-gradient` で放射状の縞を作り、`mask` で輪の形に抜きます。

```css
.dashed-ring {
  width: 90px; aspect-ratio: 1;
  border-radius: 50%;
  background: repeating-conic-gradient(var(--green) 0 20deg, #0000 20deg 30deg);
  mask: radial-gradient(closest-side, #0000 78%, #000 79%);
}
```

### 解説

1周期が30度（色20度＋透明10度）なので、12本の破線になります。本数を変えるときは、360 ÷ 本数 を1周期にします。15本なら24度です。

切れ目の位置を回したいときは `from` を使います。`repeating-conic-gradient(from -10deg, ...)` と書くと、真上に破線の中央が来ます。

**落とし穴:**

- `border-style: dashed` でも破線の輪は描けますが、破線の長さと間隔をブラウザが決めるため、本数を指定できません
- 子要素を持つ要素にこの `mask` をかけると、子要素まで消えます。その場合は背景を2枚重ねて同じ結果を出します（[worked-example.md](worked-example.md) の紋章の破線リング）

## 5.3 三角形を描く

### 問題

三角形を描きたい。

### 解決

```css
.triangle {
  width: 90px; aspect-ratio: 1;
  background: var(--green);
  clip-path: polygon(50% 0, 100% 100%, 0 100%);
}
```

### 解説

頂点を変えれば、どんな三角形にもなります。直角三角形は `polygon(0 0, 100% 100%, 0 100%)` です。

**落とし穴:** 幅と高さを0にして枠線で描く古い方法もありますが、背景にグラデーションを使えず、大きさの指定も直感的ではありません。新しく書くなら `clip-path` を使ってください。

## 5.4 斜めの帯を描く

### 問題

太さが一定の斜めの帯を描きたい。文字のNやZ、斜線、リボンに使う。

### 解決

```css
.band {
  width: 90px; aspect-ratio: 1;
  background: var(--green);
  clip-path: polygon(0 0, 30% 0, 100% 100%, 70% 100%);
}
```

### 解説

上辺と下辺の幅を同じ（ここでは30%）にすると、平行四辺形の帯になります。

**落とし穴:**

- 長方形を作って `rotate` で回す方法は勧めません。回した長方形は端が斜めに切れ、他の部品と辺をそろえるのが難しくなります
- 縦棒と斜めの帯をつなぐ文字のような形は、帯だけ別に描くのではなく、全体を1つの `polygon()` にします。10頂点の「N」がその例です

```css
.n {
  clip-path: polygon(
    17% 72%, 17% 28%, 25% 28%, 38% 56.6%, 38% 28%,
    45% 28%, 45% 72%, 37% 72%, 24% 43.4%, 24% 72%);
}
```

斜めの帯と縦棒の交点（`38% 56.6%` と `24% 43.4%`）は計算して出します。式は [formulas.md](formulas.md)。

## 5.5 平行四辺形を描く

### 問題

平行四辺形を描きたい。

### 解決

形だけなら `clip-path` で描きます。

```css
.parallelogram {
  width: 90px; height: 60px;
  background: var(--red);
  clip-path: polygon(25% 0, 100% 0, 75% 100%, 0 100%);
}
```

### 解説

`transform: skewX(-20deg)` でも描けます。こちらは角度で指定でき、枠線や影も一緒に傾きます。

**落とし穴:** `skewX` は中の文字や子要素まで傾きます。ボタンなど中身のある要素に使うときは、子要素に逆向きの `skewX(20deg)` をかけて戻します。

## 5.6 欠けた輪（弧）を描く

### 問題

一部が欠けた輪を描きたい。進捗の輪、文字のCやG、数字の5の腹に使う。

### 解決

`conic-gradient` で欠ける範囲を透明にし、`mask` で中をくり抜きます。

```css
.arc {
  width: 110px; aspect-ratio: 1;
  border-radius: 50%;
  background: conic-gradient(var(--red) 0 270deg, #0000 0);
  mask: radial-gradient(closest-side, #0000 60%, #000 61%);
}
```

### 解説

角度は真上が0度で、時計回りに増えます。`0 270deg` で4分の3周です。始まりを変えるには `conic-gradient(from 45deg, ...)` と書きます。

弧の端は、中心から放射状に切れます。端を丸くしたいときは、端の位置に小さな円を `radial-gradient` で足します。位置は5.10の式（円周上の点）で求めます。

**落とし穴と別解:**

- 枠線の一辺を透明にする方法（`border-top-color: transparent`）もありますが、欠ける範囲が90度単位になり、細かい角度を指定できません
- `shape()` が使える環境なら、弧を輪郭として直接描けます（[worked-example.md](worked-example.md) の「5」）
- 弧を直線の部品につなぐときは、接合部を拡大して目で確かめます。輪の外周が直線の部品からはみ出すことがあります

## 5.7 三日月を描く

### 問題

三日月を描きたい。

### 解決

```css
.moon {
  width: 70px; aspect-ratio: 1;
  border-radius: 50%;
  box-shadow: inset 22px -8px 0 0 #f2b705;
}
```

### 解説

内側の影を横にずらすと、ずらした分だけ縁に色が残ります。1つ目の値が月の太さ、2つ目の値が傾きです。背景は指定しません。

**別解と落とし穴:** 背景が単色なら、黄色い円の上に背景色の円を少しずらして重ねる方法もあります。こちらは背景が模様や写真だと使えません。

## 5.8 正多角形と星を描く

### 問題

正五角形、正六角形、星を描きたい。

### 解決

頂点を計算して `polygon()` に入れます。正五角形は次のとおりです。

```css
.pentagon {
  width: 160px; aspect-ratio: 1;
  background: var(--red);
  clip-path: polygon(50% 0%, 97.55% 34.55%, 79.39% 90.45%,
                     20.61% 90.45%, 2.45% 34.55%);
}
```

### 解説

正n角形の k 番目の頂点は、次の式で求めます（真上から始めて時計回り）。

- x ＝ 50 ＋ 50 × sin(360° ÷ n × k)
- y ＝ 50 − 50 × cos(360° ÷ n × k)

手計算は面倒なので、スクリプトで出します。

```js
const n = 5;
const pts = [...Array(n)].map((_, k) => {
  const a = (2 * Math.PI / n) * k;
  return `${(50 + 50 * Math.sin(a)).toFixed(2)}% ${(50 - 50 * Math.cos(a)).toFixed(2)}%`;
});
console.log(pts.join(", "));
```

星は、外側の頂点と内側の頂点を交互に並べます。頂点数を2倍にし、奇数番目だけ半径を小さく（外側の約40%に）してください。次の10頂点の星は、この方法で作った多角形です。

```css
.c5 { clip-path: polygon(50% 0%, 61% 35%, 98% 35%, 68% 57%, 79% 91%,
                         50% 70%, 21% 91%, 32% 57%, 2% 35%, 39% 35%); }
```

## 5.9 しずくと卵を描く

### 問題

角のない、有機的な形を描きたい。

### 解決

```css
.drop { width: 90px; aspect-ratio: 1; background: var(--red);
        border-radius: 0 50% 50% 50%; transform: rotate(45deg) scale(.7); }

.egg  { width: 70px; height: 90px; background: var(--cream);
        border-radius: 50% 50% 50% 50% / 60% 60% 40% 40%; }
```

### 解説

しずくは、左上の角だけ丸めない正方形を45度回したものです。回すと対角線の分だけ大きくなるので、`scale` で縮めています。

卵は8値の角丸です。スラッシュの後ろが縦方向の半径で、上の2つを60%、下の2つを40%にすると、上がすぼまります。

葉、雲、顔の輪郭など、もっと複雑な形は、この8値の角丸を持つ箱を何枚も重ねて作ります。

**落とし穴:** 8値の角丸の数値は試行錯誤になります。開発者ツールで値を動かしながら決めるのが早道です。

## 5.10 円周上に等間隔で並べる

### 問題

時計の目盛りのように、小さな形を円周上に等間隔で置きたい。

### 解決

CSSの三角関数で位置を計算します。

```html
<div class="dial">
  <i style="--i:0"></i><i style="--i:1"></i><!-- ... --><i style="--i:11"></i>
</div>
```

```css
.dial { position: relative; width: 160px; aspect-ratio: 1;
        border-radius: 50%; background: var(--green); }
.dial i {
  position: absolute;
  width: 8%; aspect-ratio: 1; margin: -4%;     /* 中心を基準点に合わせる */
  border-radius: 50%; background: var(--cream);
  --a: calc(var(--i) * 30deg);
  left: calc(50% + sin(var(--a)) * 40%);
  top:  calc(50% - cos(var(--a)) * 40%);
}
```

### 解説

`--i` が何番目か、`30deg` が1つあたりの角度（360 ÷ 12）、`40%` が半径です。`sin()` と `cos()` は主要ブラウザで使えます。

**使い分け:**

- 点ではなく線を放射状に並べたいとき（目盛り線など）は、位置を計算するより、中心に置いて `rotate` で回すほうが簡単です
- 等間隔の点や線なら、5.2の `repeating-conic-gradient` で済むこともあります
- 要素を並べるのは、1つずつ色や形を変えたい場合です

## 5.11 離れた形を1つの箱で描く

### 問題

箱が足りない。同じ色の、離れた2つの形を1つの箱で描きたい。

### 解決

2つの形を、幅ゼロの「橋」でつないで1つの `polygon()` にします。

```css
.two-squares {
  width: 160px; height: 60px;
  background: var(--red);
  clip-path: polygon(
    0 0, 40% 0,            /* 左の四角の上辺 */
    60% 0, 100% 0,         /* 橋を渡って右の四角の上辺 */
    100% 100%, 60% 100%,   /* 右の四角の下辺 */
    60% 0, 40% 0,          /* 橋を戻る */
    40% 100%, 0 100%);     /* 左の四角の下辺 */
}
```

### 解説

`40% 0` から `60% 0` へ進み、後で同じ道を戻っています。行きと帰りが重なるので面積はゼロになり、何も描かれません。

**落とし穴と使い分け:**

- 書籍の著者の環境（Chrome 153）では、24pxから360pxまで橋の線が見えることはありませんでした。心配なら、橋を箱の外（たとえば `y: -1%`）に通すと確実です
- グラデーションで描ける形なら、背景を2枚重ねるほうが簡単です。この方法は、直線で囲まれた形を複数まとめたいときに使います
- `shape()` が使える環境では、橋の代わりに `move to` 命令で輪郭を分けられます
- 円弧を含む形を橋でつなぐときは、円弧を多角形で近似します（[worked-example.md](worked-example.md) の single-div 版）
